# TPLUS V1.0

Clean Android foundation for the TPLUS Tesla digital cockpit.

## Current stage
- Android overlay service
- Transparent full-screen overlay
- Initial cockpit guide lines
- VehicleData model
- NavigationData model
- DEMO vehicle provider
- Overlay permission flow

## Next stage
Build the complete approved HUD visual:
Speedometer, Battery, NavigationInfo, PowerMeter, EfficiencyGraph,
BottomCockpitBar, BottomStatus, and Hidden Mode Tesla button.

## Build
Open the project in Android Studio and run the `app` debug configuration.
